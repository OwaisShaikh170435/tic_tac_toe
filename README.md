## How to Play

1. Player X goes first. Click (or enter) a cell to place your mark.
2. Players take turns placing X and O.
3. The first player to get 3 in a row (across, down, or diagonally) wins.
4. If all 9 cells fill up with no winner, the game is a draw.
5. Press **Restart** to play again.
